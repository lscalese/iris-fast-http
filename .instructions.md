# AI assistant instructions (Copilot, Cursor, etc.)

You are interacting with the **iris-fast-http** project, a lightweight wrapper around `%Net.HttpRequest` for InterSystems IRIS.

## Core Rules
1. **Prefer Direct API**: Do not manually generate `%Net.HttpRequest` instances. Use `##class(dc.http.FastHTTP).DirectGet()`, `DirectPost()`, `DirectPut()`, or `DirectDelete()`. **Strict Rule**: Always retrieve the client instance by reference (`Output client`) by passing `.client` as an argument (e.g., `DirectGet("url=...", , .client)` or `DirectPost("url=...", body, .client)`). This allows the developer to debug the sub-request if needed.
2. **String Configuration**: Configuration must always be passed via the first string argument (`"url=...,Header_X=Y"`). Properties like Timeout or Proxy are configured within this string (e.g., `"url=https://...,Timeout=30,ProxyServer=localhost"`).
3. **Macro and Interpolation**: Always include the `FastHTTP` macro (`Include FastHTTP`) at the top of the file (class or routine). This enables string interpolation with `$$$f()`. Example: `$$$f("url=https://httpbin.org/get,Header_Authorization=Bearer {key}")`.
4. **Native Data/JSON**: If the body is a `%DynamicObject` or `%DynamicArray`, it will be automatically converted to JSON internally. Do not manually convert it to a string beforehand. Response streams also continue to offer a `%DynamicObject`.
5. **Technical Reference**: For any complex questions regarding SSE (Server-Sent Events) classes or supported properties in the Config string, refer to the [docs/AI_REFERENCE.md](docs/AI_REFERENCE.md) file.
